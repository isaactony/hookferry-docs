These docs are built for AI tools as well as for people. You can connect an assistant or coding agent to them so it answers Hookferry questions from the current docs instead of from memory.

## Choose a connection method

| Method | Best for | What the AI gets |
| :-- | :-- | :-- |
| [MCP server](#connect-the-docs-mcp-server) | Claude, Cursor, VS Code, and other MCP clients | Search over every page, on demand |
| [Hookferry skill](#install-the-hookferry-skill) | Coding agents such as Claude Code | A short summary of what Hookferry does, its commands, and its rules |
| [Page as Markdown](#give-an-ai-a-single-page) | Any chat assistant | One page, pasted or linked |
| [llms.txt](#point-an-ai-at-llmstxt) | Tools that crawl a site | A list of every page with a one-line description |

## Connect the docs MCP server

The docs MCP server lets an AI client search these docs while it works. The server URL is:

```text
https://docs.hookferry.dev/mcp
```

<Tabs>
  <Tab title="Claude Code">
    ```bash
    claude mcp add --transport http hookferry-docs https://docs.hookferry.dev/mcp
    ```
  </Tab>
  <Tab title="Cursor and VS Code">
    Open the menu at the top of any docs page and select **Connect to Cursor** or **Connect to VS Code**.
  </Tab>
  <Tab title="Any MCP client">
    Run the installer and choose your client when prompted:

    ```bash
    npx add-mcp https://docs.hookferry.dev/mcp
    ```
  </Tab>
</Tabs>

The server is read-only. It searches public docs pages and can't access your Hookferry account, events, or API keys.

## Install the Hookferry skill

The Hookferry skill tells an agent what Hookferry does, which commands to run for common tasks, and which mistakes to avoid.

<Visibility for="humans">
Paste this prompt into your coding agent:

<Prompt description="Install the Hookferry skill in your coding agent." icon="sparkles" actions={["copy", "cursor"]}>
Install the Hookferry skill so you can help me work with webhooks.

1. Run `npx skills add https://docs.hookferry.dev`.
2. Print the name and description of each skill that was installed.
3. Summarize in one paragraph what you can now help me do with Hookferry.
4. When you answer Hookferry questions, check the docs at https://docs.hookferry.dev before relying on memory, and verify webhook signatures against the raw request body in any code you write.
</Prompt>
</Visibility>

<Visibility for="agents">
To install the Hookferry skill, run this command, then read the installed skill:

```bash
npx skills add https://docs.hookferry.dev
```
</Visibility>

To read the skill yourself, open [docs.hookferry.dev/skill.md](https://docs.hookferry.dev/skill.md).

## Give an AI a single page

Every page has a Markdown version. Use one of these options:

- Open the menu at the top of the page and select **Copy page**, then paste it into your chat.
- Select **Open in ChatGPT** or **Open in Claude** to start a chat with the page attached.
- Add `.md` to the end of the page URL, for example `https://docs.hookferry.dev/quickstart.md`.

## Point an AI at llms.txt

`https://docs.hookferry.dev/llms.txt` lists every page with its description. `https://docs.hookferry.dev/llms-full.txt` contains the full text of every page in one file. Give a tool the first file when it can fetch pages on its own, and the second when it can't.

## Get better answers from AI tools

- Say whether you use the CLI or the API. Many tasks work with both, and the steps differ.
- Include the exact error message or the `error.code` value from the API.
- Ask the AI to link the docs page it used, so you can check the answer.
